SLEMS BETTA FLOWERHORN WEBSITE
===============================

Isi:
- index.html: website satu halaman, responsive, dengan animasi CSS dan JavaScript.
- Tidak memerlukan instalasi framework atau database.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder slems_betta_flowerhorn.
3. Klik dua kali index.html untuk melihat website di browser.

Cara mempublikasikan gratis:
Opsi A — Netlify Drop
1. Buka https://app.netlify.com/drop
2. Login/daftar jika diminta.
3. Upload folder atau ZIP hasil ekstrak yang berisi index.html.
4. Netlify akan memberi URL publik.

Opsi B — GitHub Pages
1. Buat repository GitHub baru.
2. Upload index.html.
3. Buka Settings > Pages.
4. Pilih deploy dari branch main dan folder root.
5. Simpan dan tunggu link publik dibuat.
